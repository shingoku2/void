# Product Guidelines - Void

## Prose & Communication Style
*   **Tone:** Professional & Technical. Documentation and user-facing strings should be concise, direct, and focused on clarity and technical precision.
*   **Clarity over Fluff:** Avoid marketing jargon. Prioritize explaining how features work and how they impact the user's workflow.

## Brand Values & Messaging
*   **Transparency:** Openness regarding the system's inner workings, data flow, and implementation details.
*   **User Sovereignty:** Every design decision should empower the user to own their data and choose their own models and providers.
*   **Innovation:** Focus on providing novel AI interactions that go beyond simple chat interfaces.

## Visual Identity & UI Design
*   **Void Identity:** While maintaining the core VS Code layout, incorporate custom visual elements (icons, themes, specific UI components) that define the "Void" brand.
*   **Cohesive Aesthetic:** Ensure that custom elements feel like a natural extension of the editor rather than intrusive additions.

## Development Philosophy
*   **Stability & Reliability:** The core editor experience is paramount. AI features must be implemented in a way that does not compromise the stability or performance of standard VS Code functionality.
*   **Internal Focus:** For the current phase, the project roadmap and development status are managed for internal/personal use, focusing on private exploration and utility.
